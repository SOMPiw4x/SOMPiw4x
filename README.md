Special Ops Multiplayer for IW4x

This is a mod that allows you to run IW4x Multiplayer on MW2 Special Ops and Campaign maps. It has normal iw4x menus, so there is no need for console typing, bots are easy to add (see instructions) and have full waypoints. There are 3 mods with 17 maps each, all are restored from classic MW2 spec ops and campaign maps. The mod is very light, just extract it to mods folder and you will see 3 new mods to choose from. The pdf has a full list of all maps.

Features
- 3 mods, 17 maps per mod, 51 maps total, all from MW2 Campaign and Spec Ops and all fully restored
- Works Great with Bot Warfare, simply drop a copy of your "z_svr_bots.iwd" file into each mod and play!
- Every map has custom spawnpoints and waypoints
- Comes standard with 3 Gamemodes - Team Deathmatch, Free-For-All, and Domination. Any Gamemode can be added to any map
- Killstreaks restored, recalibrated and tested

Known Issues
- No loadscreens/$levelbriefing images. The loadscreen will be a green/gray checker screen, this is normal. There are a few with loadscreens hardcoded- Favela Escape, co_hunted, and oilrig.
- Burger Town and Burger Town Super Deluxe loadscreen shows the name Invasion (the name of the basemap), not sure why its just this one
- When adding bot warfare, add only the z_svr_bots.iwd to the mods, do NOT overwrite the Scriptdata/Waypoints or you may lose the SOMP waypoints
- There are only 3 Gamemode options in the mod menu - Team Deathmatch, Free-For-All, Domination. This is simply because these are the only gamemodes we can guarantee at this time. Any gamemode can be added to any map, and many maps have a number of gamemodes already while others only have the 3 defaults. The process to add a gamemode is somewhat involved but can be learned and applied to all maps. Instructions will be uploaded at a later date. 
- TO ACCESS THE FULL GAMEMODES MENU - if you want to have access to the full standard iw4x gamemodes menu while in the SOMP mods simply go to the folder for each SOMPmod "mods/SOMP_ALPHA/ui_mp" and remove the file "settings_gametypes.menu" (but keep it safe, it will come in handy if you want to make your own custom Gamemodes menu). This will return you to the standard Gamemodes menu and make it the default, but note that your map is not necessarily set up for all gamemodes listed.
