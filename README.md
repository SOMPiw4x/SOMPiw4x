Special Ops Multiplayer for IW4x
This is a mod that allows you to run IW4x Multiplayer on MW2 Special Ops and Campaign maps. It has normal iw4x menus, so there is no need for console typing, bots are integrated and have full waypoints (starts games 3v3, hit 5 in-game for bot menu). There are 3 mods with 17 maps each, all are restored from classic MW2 spec ops and campaign maps. The mod is very light (30mb for all three) just extract it to mods folder and you will see 3 new mods to choose from. The pdf has instructions and a full list of all maps.
